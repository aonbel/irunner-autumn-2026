# Пример траектории

`example_trace.jsonl` — фрагмент лога LLM-вызовов, полученный на локальном
OpenAI-совместимом mock-прокси (`scripts/fake_proxy.py`). В нём видны поля,
которые харнесс пишет на каждый вызов:

- `task_id`, `task_type`;
- выбранная `model`;
- `input_tokens`, `output_tokens`, `reasoning_tokens`;
- `cost` (в выходных токенах, входные уже поделены на 10);
- задержка, размеры промпта/ответа, число tool calls.

Полные тексты промптов намеренно не логируются: это уменьшает размер логов и
не раскрывает содержимое задач. Для отладки можно поднять mock-прокси и
посмотреть `traces.jsonl` в каталоге `IRUNNER_LOG_DIR`.
